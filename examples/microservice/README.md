# microservice

A Deployment with Ingress and an HPA behind feature flags: shows booleans becoming `includeWhen` and CEL conditionals.

```bash
chart2kro convert examples/microservice/chart -o examples/microservice
kubectl apply -f examples/microservice/rgd.yaml
kubectl apply -f examples/microservice/instance.yaml   # kind Microservice, every input at its default
```

`rgd.yaml`, `instance.yaml` and `report.json` are generated by `just examples`; CI fails if they are stale. The conversion was verified at 42 witnesses.
