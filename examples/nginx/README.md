# nginx

A web server with a ConfigMap-mounted configuration: the smallest useful conversion.

```bash
chart2kro convert examples/nginx/chart -o examples/nginx
kubectl apply -f examples/nginx/rgd.yaml
kubectl apply -f examples/nginx/instance.yaml   # kind Nginx, every input at its default
```

`rgd.yaml`, `instance.yaml` and `report.json` are generated by `just examples`; CI fails if they are stale. The conversion was verified at 24 witnesses.
