# redis

A StatefulSet with a headless Service and persistence: shows readiness for StatefulSets and isolated instances of a stateful workload.

```bash
chart2kro convert examples/redis/chart -o examples/redis
kubectl apply -f examples/redis/rgd.yaml
kubectl apply -f examples/redis/instance.yaml   # kind Redis, every input at its default
```

`rgd.yaml`, `instance.yaml` and `report.json` are generated by `just examples`; CI fails if they are stale. The conversion was verified at 30 witnesses.
